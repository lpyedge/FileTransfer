# Security policy

## Supported versions

Security fixes are provided for the latest stable major version.

| Version | Supported |
|---|---:|
| 1.x | Yes |

## Reporting a vulnerability

Please do not open a public issue for suspected security vulnerabilities.

Send a private report to the project maintainers with:

- FileTransfer version
- Operating system and deployment mode
- Minimal configuration needed to reproduce the issue
- Logs with secrets and internal paths removed
- Impact and suggested remediation, if known

The maintainers will acknowledge valid reports and coordinate a fix before public disclosure.
